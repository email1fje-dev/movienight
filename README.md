# 🍿 Movie Night v2

Movie Night is a watch-party app with AI web search, Persian subtitle detection, synchronized playback and live chat.

## Railway

Required variable:
- OPENROUTER_API_KEY = your OpenRouter API key

Optional:
- OPENROUTER_MODEL = openrouter/free
- APP_URL = your public Movie Night URL

## How it works

1. User searches a movie title.
2. The server asks OpenRouter's web-search tool to find real sources.
3. The AI returns language, Persian subtitle and Persian dub availability.
4. Only a result with a verified direct playable video URL gets an active Create Room & Play button.
5. The host controls playback; Socket.IO synchronizes everyone.
6. A ready-made Persian WebVTT subtitle is attached when a real subtitle URL is found.

The subtitle is not generated by AI.

Important: use only video/subtitle sources you are authorized to stream or embed. A normal streaming-service webpage is not automatically a direct HTML5 video source.

Rooms are stored in memory, so a Railway restart clears active rooms. Production should add persistent storage, authentication, rate limiting and stronger host permissions.
